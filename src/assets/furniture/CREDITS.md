# Furniture GLB Credits

This directory contains 12 `.glb` files used as 3D furniture models in Interior Studio.

- **`chair.glb`** — processed from a real CC0 asset (see below)
- **All other 11 files** — original procedural geometry generated by
  `scripts/generate-furniture-glbs.mjs` (v2), a Node.js script that writes raw
  GLTF 2.0 binary files. No third-party assets were downloaded or derived for
  these 11 models.

All files are released under **CC0 1.0 Universal** (public domain dedication).
You may use, modify, and distribute without restriction.

## chair.glb — real CC0 asset

| Attribute | Value |
|---|---|
| **Source** | `SheenChair.glb` from [three.js examples](https://github.com/mrdoob/three.js/tree/dev/examples/models/gltf) |
| **Original author** | Wayfair LLC / KhronosGroup glTF Sample Assets contributors |
| **License** | [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/) |
| **Original size** | 4.4 MB (with PBR textures) |
| **Processed size** | ~501 kB (~150 kB gzip) |
| **Processing script** | `scripts/process-sheenchair.mjs` |

Processing steps applied to produce `chair.glb`:
1. All textures stripped (so `applyTint()` can freely recolor the mesh)
2. All `TEXCOORD_*` vertex attributes removed
3. Material reset to pure white PBR (`metallicFactor 0`, `roughnessFactor 0.8`)
4. Extension metadata cleared
5. `@gltf-transform` `dedup()` + `prune()` + `quantize(position:10, normal:8)`

The resulting file contains only CC0 geometry — no proprietary texture data.

> **Note:** Poly Pizza (`api.poly.pizza`) was tested as a potential source for
> additional real models but was inaccessible from the build environment (host
> not in network allowlist). The 11 procedural models below were generated
> instead.

## Geometry conventions

- **Orientation**: +Y up, origin at bottom-centre of the bounding box.
  Matches the `fitToBox()` contract in `furnitureModels.js`.
- **-Z is "back"**: backrests, headboards, and wall-facing surfaces sit toward −Z;
  the "front" (where you interact with the piece) faces +Z.
- **Materials**: single PBR material, `metallicFactor 0`, `roughnessFactor 0.8`,
  no textures. Pure white base color so `applyTint()` recolors cleanly.

## Regenerating

```bash
# Regenerate the 11 procedural models
node scripts/generate-furniture-glbs.mjs

# Reprocess chair.glb from the real CC0 source (requires network access)
node scripts/process-sheenchair.mjs
```
